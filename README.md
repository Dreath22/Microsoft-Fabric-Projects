# Microsoft-Fabric-Projects
## Microsoft Fabric Data Engineering Portfolio 🚀

This repository serves as a centralized collection of End-to-End data projects developed within the **Microsoft Fabric** ecosystem. Each project demonstrates proficiency in the Medallion Architecture, moving from raw data ingestion to refined analytical insights.

* **Storage:** Delta Lake tables with ACID compliance.
* **Analysis:** SQL Analytics Endpoints and T-SQL querying.
* **Visualization:** Power BI Direct Lake reporting.
